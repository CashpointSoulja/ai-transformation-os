# ELI5: what is this?

Imagine a big school where every class is starting to use robot helpers.

Some classes love their robots and use them every day. Other classes don't know how to start, so their robots sit in a cupboard. Kids have lots of ideas for new robots ("a robot that tidies the reading corner!"), but they shout them in the hallway, so nobody writes them down. Some robots were built by kids who have moved to another school, so nobody looks after them, and one of them keeps tidying things it shouldn't.

The school hires one person to sort this out. Let's call them the **robot coordinator**.

This product is the robot coordinator's clipboard:

1. **The idea box (Intake).** Any kid can drop in an idea in their own words. No forms.
2. **The sorting helper (Triage agent).** It reads each idea and asks: how many kids would this help, how often, and how annoying is the problem today? It multiplies those together to get a score. It checks whether a robot that does nearly the same job already exists, because borrowing is faster than building. Then it puts the idea in a line, best first, and writes two sentences a grown-up can understand about why it's there. You can see every step of its thinking.
3. **The robot register (Agent fleet).** A list of every robot, who looks after it, whether it passed its last check-up, and whether it's working today. Robots with nobody looking after them are marked in red, and the coordinator looks after them until someone does.
4. **The helper team (Champions).** One kid from each class who's good with robots and helps their classmates. The chart shows which classes are using robots a lot and which are stuck, so the coordinator knows where to help first. There's also a wall of "look what we made" photos.
5. **The instruction book (Skills library).** Every robot follows written instructions. They're kept in one book, with page versions, so when one class improves an instruction, every class gets the better one.

That's it: ideas go in one place, get sorted fairly with the reasons shown, every robot has a grown-up, and the classes that are stuck get help first.
